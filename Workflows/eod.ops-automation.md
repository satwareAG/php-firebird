# EOD Workflow 3: Ops & Automation

**Purpose**: Cost tracking, environment cleanup, and automated EOD execution.

---

## Checklist

- [ ] Session cost reviewed (AI tokens, CI minutes)
- [ ] Docker development services stopped
- [ ] Temporary files and build artifacts cleared
- [ ] EOD script executed successfully
- [ ] No orphaned containers or volumes

---

## Steps

### 1. Review Session Cost

Check GitHub Actions usage for the day:

```bash
gh run list --limit 10 --json status,conclusion,name,createdAt
```

Note any failed runs that consumed minutes without value.

### 2. Stop Development Services

```bash
# Stop all running compose services
docker compose down

# Verify no containers remain
docker ps --filter "name=php-firebird"
```

### 3. Clean Temporary Files

```bash
# Remove build artifacts (safe — regenerated by make)
rm -f *.lo *.dep *.la
rm -rf modules/.libs

# Remove test logs older than 7 days
find . -name "*.log" -mtime +7 -not -path "./.git/*" -delete

# Remove coverage intermediates (keep HTML report)
find coverage/ -name "*.gcda" -delete 2>/dev/null || true
```

### 4. Clean Docker Resources (optional, weekly)

```bash
# Remove dangling images
docker image prune -f

# Remove unused volumes (careful — only if no persistent data needed)
docker volume prune -f
```

### 5. Run Integrated EOD Command

```bash
# Run the complete EOD protocol
bash scripts/daily-routine.sh eod
```

This script:
1. Checks git status (fails if dirty)
2. Prints EOD checklist status
3. Reports branch and last commit

---

## CLI Reference

| Command | What it does |
|---------|-------------|
| `bash scripts/daily-routine.sh eod` | Full EOD protocol |
| `docker compose down` | Stop all dev services |
| `docker image prune -f` | Remove dangling images |
| `gh run list --limit 5` | Check recent CI runs |
