# Archived Documentation

These documents are **historical** — they document past work, audits, or
investigations that have been completed. Current truth lives in:

- **README.md** — user-facing overview, requirements, installation
- **AGENTS.md** — agent/AI instructions, release procedure, IPADP
- **CHANGELOG.md** — chronological release history
- **specs/** — active and completed SDD specifications
- **docs/oop-api.md** — Layer 2 OOP API reference
- **docs/pdo-driver.md** — Layer 3 PDO driver reference

## Subdirectory layout

| Directory | Contents |
|-----------|----------|
| `oop/` | Superseded OOP wrapper docs (replaced by `docs/oop-api.md`) |
| `v9-v11-era/` | QA reports, migration guides, audits from v9-v11 |
| `research/` | Closed investigations, superseded gap analyses |
| `plans/` | Completed implementation plans |
| `developer-notes/` | Personal developer setup notes (not project docs) |

## Policy

- Do not edit archived files unless correcting a factual error
- If a file's content is needed going forward, extract it into an active doc
- Archive candidates: point-in-time snapshots, self-declared COMPLETE, or
  superseded by a newer spec/doc
