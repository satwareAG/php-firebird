## 2. Remaining Work Before Tag

### Phase 1: Per-Statement Timeout (#464) - MANDATORY

The only non-FB6 issue remaining in the v13.0.0 milestone. Must be implemented
and tested before rc.1.

**Files to modify** (6 files + tests):

| File | Change |
|------|--------|
| `src/cpp/fb_statement.hpp` | Add `getTimeout()/setTimeout()` to StatementWrapper (calls `IStatement::getTimeout/setTimeout`) |
| `firebird_utils.h` | Add `fbc_stmt_set_timeout()` / `fbc_stmt_get_timeout()` C declarations |
| `firebird_utils.cpp` | Implement C wrappers |
| `firebird.c` | Add `fbird_stmt_set_timeout()` / `fbird_stmt_get_timeout()` procedural functions |
| `pdo_fbird/php_pdo_fbird.h` | Add `FBIRD_ATTR_STMT_TIMEOUT` constant |
| `pdo_fbird/pdo_fbird_stmt.c` | Handle `FBIRD_ATTR_STMT_TIMEOUT` in `setAttribute()` |
| `fbird_class_statement.c` | Add OOP `Statement::setTimeout()/getTimeout()` methods |
| `stubs/*.php` | Update stubs with new functions/methods |
| `tests/fbird_stmt_timeout_001.phpt` | New test: procedural + PDO + OOP round-trip |

**Pattern**: Already established by connection-level timeout (#422).
Connection-level: `IAttachment::setStatementTimeout()` sets default for all
statements on the attachment. Per-statement: `IStatement::setTimeout()`
overrides that default for a specific statement.

**Estimated effort**: 1 session (pattern exists, 6 files).
