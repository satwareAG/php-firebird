# Specification Update: PHP 8.5 Support and Firebird 5.0+ Roadmap

**Date**: 2026-03-06
**Status**: DRAFT

## Context
Following the successful automation of Firebird client version resolution and the stabilization of the 12-combination CI matrix, this document outlines the next phase of compatibility and performance enhancements for `php-firebird`.

## Research Findings
1. **PHP 8.5 (Released Nov 20, 2025)**:
   - **Key Features**: Pipe operator (`|>`), URI extension, Object cloning with property updates, `#[\NoDiscard]` attribute, Persistent cURL share handles.
   - **Internal Changes**: OpCache is now non-optional and statically compiled. `register_argc_argv` and `disable_classes` are deprecated/removed.
   - **C Extension Impact**: Header cleanups in Zend Engine; some third-party extensions may need explicit `#include` additions (e.g., `errno.h`). No major breaking Zend API changes for database drivers identified yet, but standard `php_fbird_*` patterns should be audited against PHP 8.5 source.

2. **Firebird 5.0 (Current Stable)**:
   - **Performance**: Parallel backup/restore/sweep, compiled statement cache (up to 25% gain), improved record compression.
   - **API Extensions**: Wire protocol v18. New `isc_spb_bkp_parallel_workers` and related options for services. Support for minor ODS upgrades without backup/restore.
   - **New Features**: Multiple rows for `DML RETURNING`, scrollable cursors (network support).

3. **Firebird 6.0 (Roadmap)**:
   - Focus on further scalability and potentially more refined OO API features.

## Core Stability & Compatibility Mandate
The `php-firebird` extension is the critical base for the `doctrine-firebird-driver`. Stability and compatibility are non-negotiable.
- **Primary Stability Target**: PHP 8.4 (current) and Firebird 3.0 (baseline) MUST be 100% stable.
- **Support Window**: 
  - Lowest supported PHP: 8.2 (until EOL).
  - Lowest supported Firebird: 3.0 (until EOL).
- **Evolutionary Goal**: Newer versions (PHP 8.5+, FB 4.0+) must be evolved to reach 100% stability parity with the baseline.

## Proposed Strategy

### Phase 0: Baseline Stability Enforcement (Critical)
- [x] **Regression Testing for FB 3.0**: Ensure all FB 4.0/5.0 feature additions have robust `SKIPIF` blocks and do not leak into FB 3.0 code paths (verified via `FB_API_VER=30` builds).
- [x] **PHP 8.4 Hardening**: Audit all Zend Engine interactions for PHP 8.4 compatibility, focusing on resource-to-object migrations and strict typing.

### Phase 1: PHP 8.5/8.6 Evolution
- [ ] **Audit `fbird_connect` for persistent connection patterns**: Explore if the new persistent handle patterns in PHP 8.5 can be applied to Firebird connections for better SAPI performance.
- [ ] **Support `#[\NoDiscard]` in OO Wrapper**: Update `Firebird\Batch` and other OO classes to use the new attribute to prevent ignored results.
- [ ] **Property Hooks**: Ensure `Firebird\BatchResult` and other VO-like classes leverage property hooks if applicable to simplify the API.

### Phase 2: Firebird 4.0/5.0 Stability Parity
- [ ] **Parallel Service Operations**: Expose `parallel_workers` parameter in `fbird_service_backup`, `fbird_service_restore`, and `fbird_service_repair`.
- [ ] **ODS Upgrade**: Add `fbird_service_repair_upgrade()` to trigger the new minor ODS upgrade feature.
- [ ] **Statement Cache Monitoring**: Add functions/metadata to inspect the state of the prepared statement cache if exposed by the API.

### Phase 3: Enterprise Security (Zero-Trust)
- [ ] **Connection String Validation**: Stricter parsing of DSNs to prevent injection via protocol schemes.
- [ ] **Credential Masking**: Ensure `fbird_connection_info()` and error messages never leak sensitive DPB/TPB information in production environments.
- [ ] **Memory Safety**: Integrate `scripts/run-sanitizer.sh` into a mandatory pre-release gate.
