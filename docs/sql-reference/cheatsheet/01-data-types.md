# Cheatsheet: Data Types

Features related to data types introduced in Firebird 3.0, 4.0, and 5.0.

**Source inventory**: [feature-inventory.md rows #1-#11](../feature-inventory.md#1-data-types)

## BOOLEAN

- **Introduced**: Firebird 3.0 (CORE-726)
- **Source**: [data_types @ R3_0_7](https://github.com/FirebirdSQL/firebird/raw/R3_0_7/doc/sql.extensions/README.data_types)

**SQL**:
```sql
CREATE TABLE flags (id INT, active BOOLEAN DEFAULT TRUE);
INSERT INTO flags VALUES (1, TRUE), (2, FALSE), (3, NULL);
SELECT * FROM flags WHERE active IS TRUE;
```

**PHP**:
```php
// Procedural - returns PHP bool natively
$res = fbird_query($cxn, "SELECT active FROM flags WHERE id = ?", [1]);
$row = fbird_fetch_assoc($res);
var_dump($row['ACTIVE']); // bool(true)

// OOP
$stmt = $conn->prepare("SELECT active FROM flags WHERE id = ?");
$rs = $stmt->execute([1])->fetch();
var_dump($rs['ACTIVE']); // bool(true)
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | Y (native) | Returns PHP `bool` |
| `Firebird\*` | Y (native) | Returns PHP `bool` |
| `pdo_fbird` | Y (native) | Returns PHP `bool` |

## Identity Columns

- **Introduced**: Firebird 3.0 (CORE-1385)
- **Source**: [identity_columns @ R3_0_7](https://github.com/FirebirdSQL/firebird/raw/R3_0_7/doc/sql.extensions/README.identity_columns.txt)

**SQL**:
```sql
CREATE TABLE orders (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100)
);
INSERT INTO orders (name) VALUES ('first');
```

**PHP**:
```php
// Procedural - get last identity value
fbird_query($cxn, "INSERT INTO orders (name) VALUES (?)", ['first']);
$id = fbird_last_insert_id($cxn);
echo $id; // 1

// OOP
$conn->prepare("INSERT INTO orders (name) VALUES (?)")->execute(['first']);
$id = $conn->lastInsertId();
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | Y (native) | `fbird_last_insert_id()` |
| `Firebird\*` | Y (native) | `Connection::lastInsertId()` |
| `pdo_fbird` | Y (native) | `PDO::lastInsertId()` |

## GENERATED ALWAYS AS IDENTITY + OVERRIDING

- **Introduced**: Firebird 4.0 (CORE-5449)
- **Source**: [identity_columns @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.identity_columns.txt)

**SQL**:
```sql
CREATE TABLE accounts (
    id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR(100)
);

-- Override the identity value (requires OVERRIDING SYSTEM VALUE)
INSERT INTO accounts (id, name) OVERRIDING SYSTEM VALUE VALUES (999, 'special');
```

**PHP**:
```php
// All layers: pure SQL passthrough
fbird_query($cxn,
    "INSERT INTO accounts (id, name) OVERRIDING SYSTEM VALUE VALUES (?, ?)",
    [999, 'special']
);
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | Y (SQL) | SQL passthrough |
| `Firebird\*` | Y (SQL) | SQL passthrough |
| `pdo_fbird` | Y (SQL) | SQL passthrough |

## DECFLOAT(16) / DECFLOAT(34)

- **Introduced**: Firebird 4.0 (CORE-5525)
- **Source**: [floating_point_types @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.floating_point_types.md)
- **Gap tracked**: [#417](https://github.com/satwareAG/php-firebird/issues/417)

**SQL**:
```sql
CREATE TABLE rates (
    id INT,
    price DECFLOAT(34),
    rate DECFLOAT(16)
);
INSERT INTO rates VALUES (1,
    123456789.0123456789012345678901234,
    3.141592653589793
);
```

**PHP**:
```php
// Procedural - PARTIAL: returned as string until native DecFloat lands
$res = fbird_query($cxn, "SELECT price FROM rates WHERE id = ?", [1]);
$row = fbird_fetch_assoc($res);
echo $row['PRICE']; // string "123456789.0123456789012345678901234"

// OOP - full DecFloat class support (v12.0+)
$dec = Firebird\DecFloat::fromString("123456789.0123456789012345678901234");
echo $dec->toPrecision(34);
echo $dec->rawBytes(); // 16-byte IEEE 754 decimal128
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | P | Returned as string. Native DecFloat tracked in [#417](https://github.com/satwareAG/php-firebird/issues/417) |
| `Firebird\*` | Y (native) | `Firebird\DecFloat` class (v12.0+) |
| `pdo_fbird` | P | Returned as string. [#417](https://github.com/satwareAG/php-firebird/issues/417) |

## INT128 (Extended NUMERIC/DECIMAL)

- **Introduced**: Firebird 4.0 (CORE-4409)
- **Source**: [data_types @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.data_types)
- **Gap tracked**: [#418](https://github.com/satwareAG/php-firebird/issues/418)

**SQL**:
```sql
-- NUMERIC/DECIMAL with precision 19-38 uses INT128 internally
CREATE TABLE big_values (
    id INT,
    huge NUMERIC(38, 0)    -- stores up to 38 digits
);
INSERT INTO big_values VALUES (1, 99999999999999999999999999999999999999);
```

**PHP**:
```php
// All layers: PARTIAL - returned as string
$res = fbird_query($cxn, "SELECT huge FROM big_values WHERE id = ?", [1]);
$row = fbird_fetch_assoc($res);
echo $row['HUGE']; // string "99999999999999999999999999999999999999"

// Use bcmath or GMP for arithmetic:
$halved = bcdiv($row['HUGE'], '2', 0);
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | P | Returned as string. Native INT128 tracked in [#418](https://github.com/satwareAG/php-firebird/issues/418) |
| `Firebird\*` | P | Same. [#418](https://github.com/satwareAG/php-firebird/issues/418) |
| `pdo_fbird` | P | Same. [#418](https://github.com/satwareAG/php-firebird/issues/418) |

## TIME WITH TIME ZONE / TIMESTAMP WITH TIME ZONE

- **Introduced**: Firebird 4.0 (CORE-694)
- **Source**: [time_zone @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.time_zone.md)
- **Gaps tracked**: [#419](https://github.com/satwareAG/php-firebird/issues/419) (native types), [#478](https://github.com/satwareAG/php-firebird/issues/478) (session timezone DPB)

**SQL**:
```sql
CREATE TABLE events (
    id INT,
    event_time TIME WITH TIME ZONE,
    event_ts TIMESTAMP WITH TIME ZONE
);
INSERT INTO events VALUES (1, '12:30:00 Europe/Berlin', '2026-07-14 12:30:00 UTC');
SELECT event_time AT TIME ZONE 'America/New_York' FROM events;
```

**PHP**:
```php
// Procedural - PARTIAL: returned as string
// Workaround: use SET BIND to coerce to VARCHAR
fbird_query($cxn, "SET BIND OF TIME WITH TIME ZONE TO VARCHAR(40)");
fbird_query($cxn, "SET BIND OF TIMESTAMP WITH TIME ZONE TO VARCHAR(50)");

// Or use session timezone for automatic conversion
// (requires #478 to set at connect time):
fbird_query($cxn, "SET TIME ZONE 'Europe/Berlin'");

// Per-statement timezone via SQL passthrough:
$res = fbird_query($cxn,
    "SELECT event_time AT TIME ZONE 'America/New_York' FROM events WHERE id = ?",
    [1]
);
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | P | Returned as string. Native type in [#419](https://github.com/satwareAG/php-firebird/issues/419). Session timezone DPB in [#478](https://github.com/satwareAG/php-firebird/issues/478) |
| `Firebird\*` | P | Same. [#419](https://github.com/satwareAG/php-firebird/issues/419), [#478](https://github.com/satwareAG/php-firebird/issues/478) |
| `pdo_fbird` | P | Same + `PDO::FBIRD_ATTR_SET_BIND` can coerce. [#419](https://github.com/satwareAG/php-firebird/issues/419) |

## (VAR)BINARY(n) / BINARY VARYING(n)

- **Introduced**: Firebird 4.0 (CORE-5064)
- **Source**: [data_types @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.data_types)

**SQL**:
```sql
-- These are SQL-standard aliases for CHAR(n) CHARACTER SET OCTETS / VARCHAR(n) CHARACTER SET OCTETS
CREATE TABLE raw_data (
    id INT,
    hash BINARY(32),           -- fixed 32 bytes
    signature VARBINARY(256)   -- variable up to 256 bytes
);
INSERT INTO raw_data VALUES (1, x'DEADBEEF', x'00FF');
```

**PHP**:
```php
// All layers: binary-safe string handling
$res = fbird_query($cxn, "SELECT hash FROM raw_data WHERE id = ?", [1]);
$row = fbird_fetch_assoc($res);
echo bin2hex($row['HASH']); // "deadbeef..."
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | Y (SQL) | Returned as binary-safe PHP string |
| `Firebird\*` | Y (SQL) | Same |
| `pdo_fbird` | Y (SQL) | Same |

## SET BIND Rules

- **Introduced**: Firebird 4.0
- **Source**: [set_bind @ v4.0.7](https://github.com/FirebirdSQL/firebird/raw/v4.0.7/doc/sql.extensions/README.set_bind.md)
- **Gap tracked**: [#420](https://github.com/satwareAG/php-firebird/issues/420)

**SQL**:
```sql
-- Coerce type binding at the statement/connection level
SET BIND OF DECFLOAT TO VARCHAR(60);
SET BIND OF INT128 TO VARCHAR(40);
SET BIND OF TIME WITH TIME ZONE TO TIME;
```

**PHP**:
```php
// PDO - native support
$pdo->setAttribute(PDO::FBIRD_ATTR_SET_BIND, 'DECFLOAT TO VARCHAR(60)');

// Procedural - PARTIAL: must use SQL passthrough
fbird_query($cxn, "SET BIND OF DECFLOAT TO VARCHAR(60)");

// Note: SET BIND is session-scoped. The bind rule persists for the connection.
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | N (no DPB param) | SQL passthrough works. Native `isc_dpb_set_bind` DPB tracked in [#420](https://github.com/satwareAG/php-firebird/issues/420) |
| `Firebird\*` | N | Same. [#420](https://github.com/satwareAG/php-firebird/issues/420) |
| `pdo_fbird` | Y (native) | `PDO::FBIRD_ATTR_SET_BIND` attribute |

## Hex Literals for INT128

- **Introduced**: Firebird 5.0 (#6809)
- **Source**: [hex_literals @ v5.0.4](https://github.com/FirebirdSQL/firebird/raw/v5.0.4/doc/sql.extensions/README.hex_literals.txt)

**SQL**:
```sql
-- FB5 supports hex literals for extended numeric types
INSERT INTO big_values VALUES (2, 0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF);
SELECT huge FROM big_values WHERE id = 2;
```

**PHP**:
```php
// All layers: SQL passthrough
fbird_query($cxn, "INSERT INTO big_values VALUES (?, ?)", [
    2,
    '0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF' // pass as string
]);
```

**Driver matrix**:

| Layer | Status | Note |
|-------|--------|------|
| `fbird_*` | Y (SQL) | SQL passthrough |
| `Firebird\*` | Y (SQL) | SQL passthrough |
| `pdo_fbird` | Y (SQL) | SQL passthrough |
